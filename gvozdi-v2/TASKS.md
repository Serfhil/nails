# TASKS — открытые задачи владельца

Правила — `claude.md` §0 (чтение на старте), §4 п. 2 (запись), §9 (формат).
Здесь только открытые задачи. Выполненную или отклонённую задачу роль удаляет отсюда, итог пишет в свой `reports/<роль>.md`. Номера не переиспользуются: следующий — больше самого большого в этом файле и в `reports/*.md`.
Каждая роль на старте выбирает задачи со своей меткой; Оркестратор — ещё с меткой `?` и с несколькими ролями.

```
## T-NNN <кратко>
Роль: <Ядро|Контент|Интерфейс|Валидатор|Симулятор|Оркестратор|?>
Добавлено: <дата>, записал <роль агента>
Суть: <мысль владельца, близко к его словам>
Статус: открыта | в работе (<роль>, <дата>)
```
