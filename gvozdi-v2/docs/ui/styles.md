# styles.css — оформление

**Телефон (T-012, view.md 4)** — блок `@media (max-width: 899px)` в конце файла:
- весь текст и подписи не мельче 16 px (мелкие 13–15 px подняты; поля ввода 16 px везде — без автозума);
- цели нажатия не меньше 44 px: «Снять» в слотах, строка склада и область флажка (`.flag`, 44×44), строки лавки;
- заголовок игры в липкой шапке 18 px, кнопка «Настройки» справа не сжимается;
- переменные и квадратики мест переносятся (`flex-wrap`), строки итога дня тоже;
- `.tip-touch` — текстовая копия подсказок `title` (см. render.md), скрыта на устройствах с мышью.
`@media (max-width: 560px)`: дело в столбик — кнопка на всю ширину, ниже цена строкой и описание (иначе колонка цены 9rem сжимала кнопку до ~130 px и слова рвались посередине).
Тёмная плашка эффекта: срок теперь цветом плашки (раньше серый на тёмном не читался).
Проверка: headless Chrome, страница в iframe шириной 360 px (окно headless не уже 500 px): нет элементов за правым краем, нет целей нажатия < 44 px, нет текста < 16 px — на всех состояниях (экран со всеми раскрытыми блоками, открытый список, выбор участников, окно выбора, окно замены, итог дня, ошибка + взведённое «Начать заново», концовка, пустой вид). T-017: окно «Настройки» (два пака с длинными названием и описанием, взведённое «Начать заново») — без нарушений.

- Тема — «Выверенный деревенский дом»: CSS-переменные в одном блоке `:root` (солома `--paper`, карточка `--card`, плашка `--soft`, орех `--nut` для шапки, мох `--moss` для кнопок, `--danger` для опасности, цветовой код панелей `--honey`/`--plum`/`--leaf`/`--blue`/`--hazel`, недоступное `--off-*`). Шрифты: Nunito (текст) и Lora (заголовки и крупные числа), подключаются через `@import` в начале `styles.css`. Высота нажатия — `--tap` (48 px).
- Красный (`--danger`) — только опасность: `danger`, предупреждение стресса, нехватка (✕), взведённое второе нажатие. `seal` — нейтральная плашка с ореховой кромкой. Недоступное — без обводки и плоской заливки: у дела фон тот же, что у доступного, бледнеет только кнопка; значки ✓ ✕ ! дублируют цвет.
- Десктоп (≥ 900 px, по умолчанию): три колонки `.cols` (1fr / 1.3fr / 1fr), `#app` до 1400 px; шапка на всю ширину над колонками, липкая.
- Телефон (< 900 px): одна колонка, `max-width: 640px`, от 360 px; `overflow-x: hidden`, переносы `overflow-wrap: anywhere`; кнопки на всю ширину, высота от 48 px; поля ввода 16 px (без автозума iOS).
- Шапка с главными кнопками — `position: sticky`, всегда вверху.
- Поля ввода (`input[type=text|number]`) — бумажный фон, рамка тёмного дерева. Выпадающие списки — свои (`.dd`: кнопка со значением и список вариантов, `.dd-list` с полосой прокрутки), родной `select` не используется: его список браузер рисует сам, и стилю он не подчиняется. Флажки — свои (дерево, галочка); фокус клавиатуры — контур `--warn`.
- Полоса прокрутки (`.scroll`) — дерево на светлой дорожке (`scrollbar-color` и `::-webkit-scrollbar`).
- Заголовок панели (`h2`) — с засечками и линией под ним; название карточки на доске и в заказах (`h3`) — рубленый жирный, чтобы два заголовка не сливались.
- Дела: строка — сетка «кнопка (1fr) + цена (9rem)», кнопки одной ширины, цена столбцом справа.
- Места мастерской: `.pips` (квадратики, занято залито). Строка выбора `.choice`: текст слева, кнопка справа, список под ней. Поля закупки на рынке ниже обычных (32 px).
- Склад: строка ≈ 34 px (`--row`), флажок 24 px; доска объявлений: варианты в ряд (`.board .options`, `flex-wrap`).
- Свёртки (`.fold`) — кнопка-заголовок со стрелкой; переменные (`.vars`) — столбцом.
- Окна — `position: fixed`, по центру экрана (`margin: auto` у `.modal`, чтобы высокое окно не обрезалось сверху), прокрутка внутри окна.
- Окно «Настройки»: `.modal-head` (заголовок + крестик `.close-x` 48×48), `.about` (плашка `--soft`), `.pack-list` — пункты ≥ 44 px, текст 16 px, длинное переносится; текущий пак — `.pack.current` (мох, `--leaf-tint`), остальные — ссылки `.pack-link` с фоном `--field`.
