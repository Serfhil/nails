# storage.ts — сохранение

Назначение: работа с `localStorage` без падений.

- Ключ игры: `gvozdi-v2:<pack.id>:save` (`saveKey`); ключ состояния интерфейса: `gvozdi-v2:<pack.id>:ui` (`uiKey`, хранит только закрытый день итога).
- `read` / `write` / `remove` глотают исключения (приватный режим, переполнение).
- Хранилище недоступно → игра идёт, сообщение «Сохранение недоступно…».
- `memoryStorage()` — хранилище в памяти для тестов.
- Паки не делят сохранения: у каждого свои ключи с `id`. Переход на страницу другого пака (окно «Настройки») ничего не пишет; «Начать заново» стирает только ключи текущего пака (тест `ui/test/settings.test.ts`). Одна и та же страница пака по двум адресам (`dist/index.html` и `dist/packs/<id>/index.html`) на одном сайте видит одно сохранение. При открытии с диска (`file://`) браузер может держать `localStorage` отдельно для каждого файла или не давать его вовсе — тогда сохранения разных страниц не общие.
