# strings.ts — тексты интерфейса

Назначение: единственное место для подписей самого интерфейса: кнопки («Заняться делом», «Спать до утра», «Начать заново», «Сдать товар», «Отказаться», «Подробности», «Понятно»), заголовки панелей, служебные сообщения (сохранение отклонено, хранилище недоступно).

Правила:
- Только рамка интерфейса, по-русски. Тексты игры (названия, описания, причины недоступности, итоги) приходят из вида.
- Подписей ролей и слотов здесь нет: они приходят из вида (`role_name`, `slot_name`, core.md 2.1).
- Окно замены оборудования: `replaceWhat` («Что заменить:»), отказ — `replaceCancel` («Не менять»).
- Подтверждения второго нажатия: `restartConfirm`, `declineConfirm`.
- Окно «Настройки»: `settings` (кнопка в шапке и заголовок окна), `settingsClose` (подпись крестика), `packVersion` («версия»), `packChoose` («Выбор пака»), `packCurrent` («Открыт сейчас»).
