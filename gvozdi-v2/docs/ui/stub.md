# stub.ts — заглушка вида

Назначение: разработка и тесты интерфейса без движка.

- `emptyView()` — вид, где все панели пусты.
- `fullView()` — заполнено всё (контракт 2.1): действия (разовое, с партнёром, с кандидатами, недоступное, назначаемое, с `replace`), три персонажа (герой, работник, недееспособный питомец) с `role_name`, `slot_name`, `equippable`, `display`; `hire_pool` из двух кандидатов; мастерская с двумя единицами оборудования, склад, вещи, рынок, доска, заказ, эффекты.
- `sampleOffer()` — окно выбора с доступным и недоступным вариантом.
- `StubGame` — фейковый `Game`: правдоподобно отвечает на все команды контракта, пишет их в `log`, отклоняет команды при открытом окне и после концовки.
- `stubApi()` — `createGame` / `loadGame`; несовместимое сохранение → исключение.

Тексты заглушки — выдуманные тестовые данные; в рендер они попадают только через вид.
