# app.ts — контроллер

Назначение: `createApp({ api, pack, packs, storage, random, onRender })` держит игру и `UiState`, превращает события интерфейса (`UiEvent { act, data, value, checked }`) в команды, сохраняет после каждой успешной команды.

## Правила
- Запуск: есть сохранение → `loadGame`; исключение → сообщение «Сохранение не подошло…» и новая игра. Нет сохранения → `createGame(pack, seed)`; зерно — `random()` (в браузере `Math.random`, только для зерна).
- `perform(cmd)`: `ok` → `lastEvents = events`, `lastStop = stop.text` (для `work_until_stop`), сохранение `game.save()`; не `ok` → сообщение `error.text`, состояние и сохранение не трогаются. Вид всегда берётся из `Result.view`.
- Под окном проходят только его кнопки: окно выбора — `choose` этого предложения; итог дня — `summary-close`, `summary-details`; концовка — `restart`; настройки — `restart`, `settings-close`. Остальное игнорируется, движок не вызывается.
- Второе нажатие: `restart` и `decline:<id>`; любое другое событие сбрасывает ожидание.
- Действие: без выбора участников — сразу `do_action`; иначе открывается выбор, `pick-go` отправляет, `pick-cancel` закрывает.
- Если у действия `replace` не `null`, готовая команда не уходит, а открывает окно замены: `replace-choose` (item из `replace.options`) → `do_action` с `replace`; `replace-cancel` — закрыть без команды. Под окном проходят только эти две кнопки.
- Рынок: ввод количества и галочки лавки меняют только черновик; `market-go` отправляет `market_trip`, после успеха черновик очищается.
- «Итог дня» закрывается без команды; закрытый день запоминается в хранилище (ключ `…:ui`), чтобы итог не всплывал после перезагрузки.
- Окно «Настройки» (view.md 3.14): `settings-open` открывает (только когда нет другого окна), `settings-close` закрывает (крестик или тап мимо — `data-backdrop` в dom.ts). `packs` — список паков сборки (packs.md); выбор другого пака — обычная ссылка, контроллер не участвует.
- «Начать заново» (в настройках и на концовке; в шапке его нет): стирает сохранение сбрасывает состояние интерфейса, новая игра с новым зерном.

## Пример
```ts
const app = createApp({ api: { createGame, loadGame }, pack, storage: localStorage, random: Math.random });
app.handle({ act: "work" });            // work_until_stop, перерисовка, сохранение
app.handle({ act: "decline", data: { id } });  // ждёт второго нажатия
```

## События групп действий
`cat-fold` (`id`) — раскрыть/свернуть группу list. `cat-pick` (`cat`, `value` = id действия) — выбрать действие в группе select; недоступное или чужой категории отклоняется (`false`).
