# styleguide — витрина интерфейса

Статичная страница со всеми панелями, окнами и состояниями на выдуманных данных заглушки (`ui/src/stub.ts` плюс дополнения в `ui/styleguide.ts`). Нужна, чтобы стилизовать `styles.css`, не запуская игру и не трогая проект.

- Генератор: `ui/styleguide.ts`. Рендерит `renderApp` на готовых видах, ничего не считает.
- Запуск: `npx tsx ui/styleguide.ts [папка]`, по умолчанию `docs/ui/styleguide/` → `index.html` + `styles.css` (копия `ui/src/styles.css`).
- Стилизация: правьте `docs/ui/styleguide/styles.css`, обновляйте страницу. Готовый CSS перенесите обратно в `ui/src/styles.css` (его копию генератор перезапишет при следующем запуске).
- Состояния (14 рамок с оглавлением): экран целиком, телефон 360 px, выбор участников действия, окно выбора, окно замены, итог дня (свёрнут и подробно), ночь, ошибка команды, настройки на 360 px (три пака, длинные тексты), настройки со взведённым «Начать заново» и одним паком без описания, три концовки, пустой вид.
- Окна `position: fixed` показаны внутри рамок (рамка с `transform`), поэтому не накрывают всю страницу.
- Страница статична: кнопки не работают; шрифты Nunito / Lora подгружаются с Google Fonts.
