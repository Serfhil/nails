# Модификаторы (`modifiers.ts`)

**Назначение.** Единый механизм состояния: эффекты, состояния и флаги. Собирает все модификаторы, действующие на сущность, накладывает и снимает их, готовит `EffectView`.

## Откуда берутся
| Источник | Срок | На кого |
|---|---|---|
| эффект `add_modifier`, `modifiers` шаблона персонажа | `days`, `forever`, `while` (из шаблона или эффекта) | цель эффекта / сам персонаж |
| предмет в слоте персонажа | пока предмет в слоте (`source`) | `target` шаблона: `owner` — держатель, `hero`, `world` |
| оборудование в мастерской | пока стоит (`source`) | `owner` — мастерская, `hero`, `world` |
| `modifiers` типа мастерской | пока мастерская есть | то же |
| ступень лестницы | пока ступень текущая | `owner` — владелец переменной, `hero`, `world` |

Предмет в инвентаре не действует. Модификатор, наложенный на экземпляр предмета, с переменной не предметного владельца, действует на держателя предмета.

## Поля шаблона
`var`, `target`, `applies_to` (`value`/`change`), `direction`, `op` (`add`/`pct`/`mult`), `value` (число или `{"$data"}` из данных модификатора), `value_from` (`{var, subject, baseline, per_point}`; `subject` относительно владельца: `self`, `hero`, `world`, `workshop`, `char:<id>`), `action_tags`, `duration`, `flag`, `incapacitates`, `may_be_permanent`, `stack`, `on_expire`, `visible`, `show_numbers`, `tags`, `data_defaults`.

## Правила
- **Наложение** (`addModifier`): `stack: false` и уже есть такой на той же сущности — срок продлевается до большего, данные дополняются; `stack: true` — новая копия. `duration.kind: "source"` при наложении эффектом живёт бессрочно.
- **Снятие** (`remove_modifier`): по `template` или `tag`, `count` копий (не задано — все), старые первыми; снимаются только хранимые (от источника — нельзя). `on_expire` при снятии не выполняется.
- **Истечение**: утром `days − 1`, на нуле — снятие, `on_expire`, сигнал `modifier_expired`.
- **`while`**: снимается, как только условие (субъект `self` — владелец) ложно; проверка — в `settle()`.
- **Негативный**: `incapacitates`, или модификатор ухудшает переменную с учётом `good` (`up` по умолчанию). Для `change` с `direction: "loss"` и `pct`/`mult` рост величины означает большее снижение.
- **Числа для игрока** (`numbers`): `"<имя переменной> +10%"`, `"… −0.1"`, `"… ×0.5"`; для модификаторов изменений — `"<имя> ▲ −50%"` (▲ — прирост, ▼ — снижение, ▲▼ — любое). `null` у флагов и при `show_numbers: false`. Слов движка в строке нет — только имя переменной из пака и знаки.
- `text` модификатора подставляет его данные: `"Обещали занести {amount} мон."`.

## Пример
```json
{ "id": "cozy_evening", "var": "stress", "applies_to": "change", "direction": "gain", "op": "pct", "value": -50,
  "duration": { "kind": "days", "n": 1 } }
```
Ковка +4 стресса → +2; отдых −8 → −8. В виде: `numbers: "Усталость ▲ −50%"`, `days_left: 1`, `negative: false`.
