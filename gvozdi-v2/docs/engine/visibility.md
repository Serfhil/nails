# Видимость (`view.ts`, `events.ts: visibleKeys/checkVisibility`)

**Назначение.** «Закрытое не видно вообще»: в обычном виде нет скрытых сущностей; переходы в видимость дают сигнал.

## Правила
- `visible` — условие (`null`/нет — видно, `false` — никогда, CI-004). Субъект `self`: переменная — владелец; модификатор — владелец; персонаж — он сам; мастерская — она; товар — герой.
- Действие: видимость — `open_when` (субъект — герой); `enabled_when` и расход — серое с причиной. Вариант предложения — так же (`open_when` / `enabled_when` + `cost`). Предмет лавки — `open_when`.
- Скрытые персонажи, переменные, модификаторы, товары, мастерские, варианты в `View` отсутствуют полностью. Модификатор с `show_numbers: false` показывается без чисел (`numbers: null`).
- **`became_visible {kind, id, owner}`** — при переходе из невидимого в видимое для сущностей с условной видимостью: `action`, `variable` (`owner` — id владельца), `good`, `character`, `item` (лавка). Состояние «было видно» хранится в сохранении. Видимое сразу после старта сигнала не даёт. Первый день открытия — `debugView().opened["<kind>:<…>"]`.
- Движок об открытиях не сообщает: сообщение пишет событие пака на `became_visible`.

## Пример
```json
{ "id": "pastry_discovered", "trigger": { "signal": "became_visible", "conditions": [
    { "type": "data", "name": "id", "op": "==", "value": "bake_pastry" } ] },
  "repeat": { "max": 1 }, "effects": [ { "type": "notify", "text": "…", "popup": true } ] }
```
