# Сохранение и детерминизм (`state.ts`, `rng.ts`, `game.ts`)

**Назначение.** Одно зерно + пак + команды = один результат; сохранение восстанавливает игру точно.

## ГСЧ
`sfc32`, состояние — 4 числа uint32, зерно разворачивается `splitmix32`. Все случайности (брак, пулы, случайный участник) — только через него, в фиксированном порядке. Порядок обхода персонажей — порядок появления в игре.

## Что в сохранении
`save()` — JSON `{ format: "gvozdi-engine-save", save_version, pack_id, pack_version, state }`. `state` (`State` в `state.ts`): время; переменные мира, персонажей, мастерских, предметов; экземпляры предметов и их места; модификаторы со сроками и данными; мастерские и приписка; склад, галочки, виденные товары; пул найма; назначения, прогресс партий и торговли; очередь окон и доска; обязательства; счётчики и последние дни событий; прошлые значения событий по условию, видимости, лестниц, недееспособности; реестры открытого и сработавшего; итог дня, уведомления, движения денег за день; деньги прошлого утра; концовка; ошибки выполнения; счётчик id; состояние ГСЧ; `save_version`.

Переходные данные команды (очередь событий, строки ответа) в сохранение не входят: между командами они пусты.

## Загрузка
`loadGame(pack, save)` бросает `Error` с текстом, если: не JSON; не сохранение движка; `save_version` другая; сохранение от другого пака (`pack.id`) или другой версии пака (`pack.version`). Миграции нет.

## Пример
```ts
const s = game.save();
const again = loadGame(pack, s);
// again.view() совпадает с game.view(); дальнейшие команды дают одинаковые результаты
```
