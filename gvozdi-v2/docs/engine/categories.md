# Категории действий

Назначение: сгруппировать действия в главной панели. Движок категории не использует в расчётах, только отдаёт в вид (core.md 4.9, 4.9.1, 5.3).

## Пак
- `categories.json` — необязательный массив `{ id, name, view }`. Порядок записей — порядок групп.
- `view` необязателен: `list` (по умолчанию) или `select`. Движок значение только передаёт.
- `actions[].category` — необязательно, `id` категории или `null`. Действие без категории показывается вне групп.

## Вид
- `ActionView.category` — `id` или `null`.
- `View.categories` — `{ id, name, view }` только для категорий, где есть хотя бы одно ОТКРЫТОЕ действие (`open_when`, 3.12), в порядке файла. Закрытое действие категорию не удерживает; серое (`enabled: false`) удерживает.
- Нет файла или поля — `categories: []`, `category: null`.

## Реализация
`engine/src/pack.ts` (`PackIndex.categories`), `engine/src/view.ts` (сборка), типы в `engine/src/types.ts`.
Неизвестный `category` у действия движок не проверяет (это V003 валидатора): `id` просто отдаётся, в `View.categories` такой группы не будет.

## Фикстура
`fixtures/mini-pack/categories.json`: `baking` (select) и `care` (list); действия без категории — найм, покупки, обучение и др. Тест: `engine/test/categories.test.ts`.
