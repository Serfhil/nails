# Действия, расход, расчётные величины (`actions.ts`, `costs.ts`, `calc.ts`)

**Назначение.** Всё, что тратит время: доступность, разовые действия, поручения (партии), начисления за час, брак, торговец.

## Поля действия
`id`, `name`, `mode` (`once`/`assignable`/`both`), `hours`, `speed_scaled`, `roles` (`actor` обязателен, `partner?`, `candidate?`; `who`: `hero`, `worker`, `hero_or_worker`, `any`, `pool`; `where` — условие, `self` = участник), `open_when`, `enabled_when`, `disabled_text`, `cost`, `outputs`, `per_hour` (`target`, `var`, `add`, `scale_by?`), `effects`, `tags`, `text`, `description`.

**`description`** — необязательная строка для игрока (пояснение к действию); `null` или отсутствие поля — валидно, пак без него работает. Движок только пробрасывает её в `ActionView.description` (`null`, если не задано); на расчёт не влияет.

## Доступность (порядок проверок)
1. `open_when` (субъект — герой и исполнитель) и, если действие ставит оборудование, ему есть место (не случай 1, см. hiring-and-workshops.md) — иначе действия нет в виде, команда — `not_available`;
2. состав ролей (`who`, `where`, разные персонажи) — иначе `invalid`;
3. `enabled_when` — иначе `requirement_unmet` с причиной. При замене оборудования (случай 4) нужен `replace`, иначе `requirement_unmet` с `replace_warning`. Для действий с эффектом `hire` нужно свободное место (`reason_workers_full`);
4. расход — `insufficient`, `reason_cost` по первой недостающей строке;
5. участники дееспособны — `incapacitated`;
6. ночь — `reason_night`; не успевает до `day_end` — `reason_no_time` (только разовые).

`ActionView.replace` — предупреждение и варианты замены (иначе `null`); при подсчёте `enabled` замена считается выбранной. `ActionView.enabled` — есть хотя бы один допустимый состав; `reason`/`cost`/`hours` — по «основному» составу (герой-исполнитель, если подходит). `roles` — подходящие дееспособные персонажи (кандидаты — видимые из пула). Для `mode: "assignable"` `enabled` — есть кому поручить.

## Длительность
`speed_scaled`: разовое — `ceil(hours / speed)` часов исполнителя (скорость с тегами действия); назначение — прогресс `speed / hours` партии за час. Без `speed_scaled` — `hours`.

## Разовое действие
Расход списывается сразу → идут часы (исполнитель и партнёр заняты; остальные работают по назначениям; каждый час — `per_hour`) → брак или выходы → `effects` → строка `text` (подстановки `{actor}`, `{partner}`, `{candidate}`) → сигнал `action_done {action, actor, partner}`.

## Назначение
Каждый рабочий час: если партия не начата — проверка расхода; не хватает → простой и (первый раз за команду) сигнал `idle_no_cost {action, actor}`; иначе расход списан, партия начата. Затем `per_hour`, прогресс += скорость/часы; на каждой целой партии — завершение и сразу следующая партия с переносом остатка (если расход выполним; иначе остаток теряется). Назначение, переставшее быть доступным (закрыто, `enabled_when` ложно), — простой без сигнала.

**Брак.** Если есть `outputs`: с вероятностью итога `defect` исполнителя партия в брак — выходов и эффектов нет, расход потерян, строка `log_batch_defect`, сигнал `batch_defect`. Иначе выходы на склад (`log_batch_done` на каждую строку выхода), эффекты, `action_done`.

**Начисления за час.** `add × scale_by` (итог переменной исполнителя) к цели через модификаторы изменений.

**Торговец** — назначение `{kind: "trade"}`, см. market-and-trade.md.

## Расход (`costs.ts`)
Строки `{good, qty}`, `{var, qty}` (переменная мира — у мира, иначе у исполнителя), `{var, from, qty_from}` (количество — итог переменной `qty_from` у субъекта `from`). Выполним, если каждого хватает (итог ≥ qty). Списывается всё сразу и ровно. `CostLine`: `{name, need, have}`.

## Расчётные величины
| Имя | Значение |
|---|---|
| `wealth` | деньги + `stock_value` |
| `stock_value` | Σ количество × `good.price` |
| `cost_hours` | по назначенным дееспособным исполнителям действия (или всем): для каждого ресурса расхода — запас / расход в час; минимум. Нет расхода — бесконечность (`null` в отладочном виде; любое «<» ложно) |
| `income_yesterday`, `expense_yesterday` | суммы из итога прошлого утра |

## Пример
```json
{ "id": "bake_bread", "mode": "both", "hours": 1, "speed_scaled": true,
  "roles": { "actor": { "who": "hero_or_worker" } },
  "cost": [ { "good": "flour", "qty": 1 } ], "outputs": [ { "good": "bread", "qty": 2 } ],
  "per_hour": [ { "target": "actor", "var": "bake_xp", "add": 1, "scale_by": "learn_speed" } ] }
```
Работник со скоростью 1.2 за 4 часа делает 4 партии и начинает пятую (прогресс 0.8, мука за неё уже списана).
