# Эффекты (`effects.ts`)

**Назначение.** Применяет списки эффектов пака в контексте (участники, данные, источник денег).

## Цели
`hero`, `self`, `actor`, `partner`, `candidate`, `participant`, `world`, `workshop`, `all_workers`, `char:<id>`. Цель не найдена — эффект пропускается. Любое числовое поле (и значения в `data`) можно заменить на `{"$data": "имя"}`; отсутствующее имя — ошибка выполнения в `debugView().errors`, значение 0.

## Типы
| type | Поведение движка |
|---|---|
| `var` | `add` — через модификаторы изменений; `set` — прямо. Деньги мира попадают в итог дня с источником контекста |
| `goods` | `qty` > 0 кладёт, < 0 забирает (не ниже 0) |
| `add_modifier` | `template`, `target`, `duration?`, `data?` (см. modifiers.md) |
| `remove_modifier` | `template` или `tag`, `count?` |
| `give_item` | инструмент: `hero` — в инвентарь, другой персонаж — в свободный слот, иначе в инвентарь. Оборудование — в мастерскую цели (у персонажа — в его мастерскую) по 4 случаям core.md 3.7 (см. hiring-and-workshops.md); что заменить, берётся из `do_action.replace` |
| `remove` | `what: item` (`item` — тип; у героя — слоты и инвентарь), `workshop` (оборудование уничтожается, работники без приписки), `character` (не героя) |
| `hire` | `candidate` или `char:<id>`; только из пула и при свободном месте (иначе ошибка выполнения) |
| `add_to_hire_pool` | в пул, если персонажа нет в игре и в пуле |
| `add_character` | в игру без найма; `as`: `worker` (работник, приписка при одной мастерской), `family`; без `as` — по роли шаблона |
| `add_workshop` | новая мастерская; первая — приписывает неприписанных работников |
| `replace_workshop` | апгрейд, см. hiring-and-workshops.md |
| `notify` | строка в уведомления и в `Result.events`; `kind?` (`info` по умолчанию); `popup: true` — ещё окно `now` с одной кнопкой `texts.popup_ok` |
| `show_offer` | предложение с участником и данными источника + `data` эффекта |
| `run_event` | ставит событие в очередь с `data`; участник — `participant` эффекта, иначе по правилам события, иначе участник источника (CI-007) |
| `end_game` | `title`, `text`, `tag` (`goal`/`fail`); дальнейшие эффекты не выполняются |

Подстановки в тексты: `{participant}`, `{actor}`, `{partner}`, `{candidate}` — имена; остальные — данные контекста.

## Пример
```json
"on_fail": [ { "type": "run_event", "event": "order_failed", "data": { "penalty": -10 } } ]
```
